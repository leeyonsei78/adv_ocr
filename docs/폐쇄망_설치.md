# 폐쇄망 설치·운영 안내

이 프로그램은 외부 LLM·클라우드·CDN 을 쓰지 않습니다. 웹 화면도 외부 글꼴/스크립트 없이 동작하며, OCR 모델은 `models/` 에 포함되어 있어 **설치 후에는 인터넷이 필요 없습니다.**

> 보안 점검 결과와 운영 권고는 [보안_검토.md](보안_검토.md) 참고.

## 1. 인터넷 되는 PC 에서 반입 묶음 만들기
```bash
git clone https://github.com/leeyonsei78/adv_ocr && cd adv_ocr
# 폐쇄망 PC 가 Windows 64bit / 파이썬 3.11 이라면:
python scripts/make_offline_bundle.py --out adreview_offline --platform win_amd64 --python-version 3.11
```
- `adreview_offline/wheels` (파이썬 패키지, Windows 기준 약 280MB) + `adreview_offline/app` (프로그램·설정·OCR 모델) 이 만들어집니다.
- `--platform`/`--python-version` 은 **폐쇄망 PC** 기준입니다. 생략하면 이 PC 와 같은 환경용으로 받습니다.
- 폐쇄망 PC 의 파이썬(3.10~3.13 권장)이 미리 설치돼 있어야 합니다. 파이썬 설치 파일도 함께 반입하세요.

## 2. 폐쇄망 PC 에서 설치
`adreview_offline` 폴더를 통째로 옮깁니다. 묶음에는 `SHA256SUMS.txt` 가 있으니 반입 후 `python app\scripts\verify_bundle.py` 로 변조 여부를 확인하세요.
설치는 `app\run.bat` 최초 실행 때 자동으로 되며(`app\install.bat` 로 먼저 설치만 할 수도 있음), 가상환경(`.venv`)을 만들어 `wheels` 에서만 설치합니다(인터넷 접속 없음).

## 3. 실행 — `run.bat` 더블클릭
`app` 폴더의 **`run.bat`** 을 실행하면 (최초 1회는 `..\wheels` 에서 자동 오프라인 설치 후) 서버가 뜨고 **브라우저에 화면이 자동으로 열립니다.** 종료는 창을 닫거나 Ctrl+C.
(Linux: `sh run.sh`)

| 용도 | 방법 |
|---|---|
| 본인 PC 에서만 사용 | `run.bat` 그대로 (127.0.0.1:8080) |
| 사내망에 공유 (서버 PC) | `config\run.env` 에 아래처럼 적고 `run.bat` 실행 |

`config\run.env` 예시 (줄 맨 앞 `#` 은 주석):
```
ADREVIEW_HOST=0.0.0.0
ADREVIEW_PORT=8080
ADREVIEW_PASSWORD=검수자암호
ADREVIEW_ADMIN_PASSWORD=관리자암호
ADREVIEW_RETENTION_DAYS=90
```
> run.env 는 평문이므로 서비스 계정만 읽도록 파일 권한을 제한하세요. 암호에 `^ & % !` 같은 특수문자는 피하세요.

사내망 공유 시 **비밀번호를 반드시 설정**하세요 (검수자 암호 = 화면 접속, 관리자 암호 = 검수 기준 수정. 관리자 암호를 생략하면 검수자 암호로도 기준을 수정할 수 있습니다).
- 로그인할 때 이름을 입력하며, 검수 요청자·기준 변경자 이력에 이 이름이 기록됩니다.
- 비밀번호 5회 오류 시 1분간 잠깁니다. 검수·기준 변경·로그인은 `output/web/audit.log` 에 남습니다.
- 통신은 http 입니다. 암호화가 필요하면 사내 프록시(https 종단)를 앞에 두세요.

## 4. 사용 순서
1. **검수 기준 관리**에서 사내 광고심의 규정에 맞게 룰·점검표·상품 마스터를 수정합니다 (예시 값은 그대로 쓰면 안 됩니다).
2. **검수** 화면에 PPTX·이미지·PDF 를 올립니다. 결과 리포트 상단에 *적용된 기준 버전*이 표시됩니다.
3. 결과(HTML·엑셀)를 담당자가 확인하고 최종 판단합니다.

## 5. 기준 문서(HWP/Word/PDF) 색인
```
python -m adreview build-reference reference_docs --out output/ref_index.json
```
`output/ref_index.json` 이 있으면 검출 항목마다 관련 약관·규정 조항이 함께 표시됩니다. 규정이 개정될 때만 다시 만듭니다.

## 6. 운영 시 유의
- **백업**: `config/`(기준)와 `config/history/`(변경 이력·백업), `output/web/`(검수 결과·감사 로그)를 정기 백업하세요.
- **사양**: 8GB 메모리 PC 에서 포함된 mobile 모델로 동작을 확인했습니다. 이미지 1장 처리에 수 초~십수 초가 걸립니다. 더 정확한 서버용 탐지 모델(약 85MB, 6GB+ 메모리)은 `config/ocr.json` 으로 경로만 바꿔 쓸 수 있습니다.
- **Tesseract 대안**: Paddle 이 어려우면 `--engine tesseract` (Tesseract 와 한국어 데이터 `kor.traineddata` 를 별도 반입). 정확도는 낮습니다.
- **OCR 한계**: 아주 작은 글씨(푸터·심의필)와 저해상도 이미지는 놓칠 수 있습니다. 가능하면 원본 PPT·원본 이미지로 검수하세요.
- **이 도구는 1차 점검 보조**입니다. 최종 판단은 담당자가 합니다.

### config/ocr.json (선택)
```json
{"paddle": {"det_model_dir": "models/PP-OCRv5_server_det", "rec_model_dir": "models/korean_PP-OCRv5_mobile_rec"}}
```
